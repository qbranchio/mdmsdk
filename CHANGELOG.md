# Changelog

## 0.1.0

First release.

- Go and Python SDKs over every public operation of the mdm API: tenants, members, groups, devices, settings, profiles, assignments, commands, tenant queries, activity, tokens, account, webhooks, and credential holders.
- Account client credentials and delegated tokens.
- Retries on transient failures with a stable Idempotency-Key; typed errors by problem code; lists as iterators, which follow a paged list's cursor.
- Webhook verification (Standard Webhooks, secret rotation) and typed events.
- Docs site with an in-browser terminal, an agent skill, and llms.txt.
