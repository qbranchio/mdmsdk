# mdmsdk

Go and Python SDKs for the mdm API: manage tenants, members, groups, devices, profiles, and commands for Apple devices.

> 0.1.0. The Python package installs from this repository until it is on PyPI.

```sh
go get github.com/qbranchio/mdmsdk
pip install "mdmsdk @ git+https://github.com/qbranchio/mdmsdk@v0.1.0#subdirectory=python"
```

For agents: `npx skills add qbranchio/mdmsdk --skill mdmsdk -a claude-code`.
