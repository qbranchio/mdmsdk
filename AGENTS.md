# AGENTS.md

## Project

mdmsdk is the public SDK for the mdm API, in Go (repo root, `github.com/qbranchio/mdmsdk`) and Python (`python/`, PyPI `mdmsdk`), plus the developer docs (`site/`) and an agent skill (`skills/mdmsdk`). The API server is private; this repo holds only its published contract.

## Layout

- `openapi/openapi.yaml`: the published contract. Generated by the server (`mdm openapi --public`) and synced here by PR. Never edit it.
- `openapi/SOURCE`: the server release the contract came from.
- `methods.yaml`: every public operationId and its SDK service and method. Both SDKs generate their services from it.
- `scenarios/*.yaml`: behavior both SDKs must show (retries, errors, idempotency, pagination, webhooks). See `scenarios/README.md`.
- `api/` (Go) and `python/src/mdmsdk/_gen` (Python): generated. Never edit.
- `examples/`: one runnable file per task in curl, Go, and Python. The docs and the skill embed them.

## Rules

- Change behavior in `scenarios/` first, then both SDKs, in the same PR.
- Never hand-edit generated code; change the generator inputs and run `just gen`.
- A public operation must have a `methods.yaml` entry; CI fails otherwise.
- Examples must run in CI.
- Docs: one idea per page, no filler. Agent docs: imperative, task-shaped.

## Commands

```sh
just gen     # regenerate Go and Python from openapi/ and methods.yaml
just test    # go test -race ./... and pytest
just lint    # golangci-lint, ruff, pyright, drift checks
```

## Git

- Branches: `feat/`, `fix/`, `chore/`. Never commit to main.
- Signed commits, conventional prefixes, single-line subjects.
